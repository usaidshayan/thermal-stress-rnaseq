# thermal-stress-rnaseq

Whole-body RNA-seq of 48 *Lucilia sericata* L4 larvae after 3 h at 4, 22 or 38 °C. Compares an experimental evolution line (LD9) with three high-diversity founder-cross lines. PhD chapter 4.

Snakemake pipeline on NeSI (Slurm). Settings are in `config/config.yaml` and the Slurm profile is in `profiles/slurm/`. Reads go to the shared *L. sericata* reference (GCF_015586225.1).

Work in progress, more to come once the sequencing data is in.
